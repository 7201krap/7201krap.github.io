AI / ML basics

The exam touches AI only lightly. This is the one definition that came up.

Network capacity

  • The capacity of a neural network is the number of patterns it can store and later recall correctly.
  • The classic example is a Hopfield network used as an associative memory: you "store" a set of patterns in the weights, and capacity is how many patterns you can store before recall starts to fail. Roughly speaking, more neurons means more capacity.
