Algorithms

Hash table

  • When a collision occurs, it has to be handled. The two main approaches are chaining (closed addressing) and open addressing. Chaining uses a linked list at each slot; open addressing uses a rule to store the value under a different key. Open addressing methods include linear probing, quadratic probing, and double hashing.
  • Collision: two keys map to the same slot. The situation where a newly inserted key maps to an already occupied slot is called a collision and must be handled by some collision-handling technique (GeeksforGeeks).

BFS and DFS

  • Time complexity of BFS: O(V + E) with an adjacency list; O(V²) with an adjacency matrix.
  • Time complexity of DFS: O(V + E) with an adjacency list; O(V²) with an adjacency matrix.

Topological sort

  • Orders the nodes of a DAG (directed acyclic graph).
  • Time complexity is O(V + E).
  • Method: list the vertices with in-degree 0 in order. Remove a vertex with in-degree 0 together with its outgoing edges. Repeat.

Shortest path problems

  • Single source: shortest paths from one source node S to every other node (Bellman–Ford, Dijkstra).
  • Single pair: shortest path from a source S to a destination T.
  • All pairs: shortest paths between every pair of nodes (Floyd–Warshall, Johnson).
  • Important: any sub-path of a shortest path is itself a shortest path.
  • The longest path problem on a DAG can be solved in polynomial time.

Bellman–Ford (not greedy)

  • Works on both directed and undirected graphs.
  • It can handle directed graphs with negative weights, as long as there are no negative cycles (Baeldung).
  • In an undirected graph, negative weights are not allowed. Negative cycles are never allowed.
  • Time complexity: O(EV) = O(V³). Every edge is relaxed V − 1 times.

Dijkstra (greedy)

  • Works on both directed and undirected graphs.
  • Assumes there are no negative weights.
  • Bellman–Ford and Dijkstra give the same final result.
  • Time complexity: O(V²), or O(V + E log V) with a min-priority queue.

Floyd–Warshall (dynamic programming)

  • Works on both directed and undirected graphs.
  • For directed graphs, negative weights are allowed.
  • Finds the shortest path length between every pair of nodes (all-pairs shortest path).
  • Time complexity: O(V³).

Johnson's algorithm

  • On sparse graphs, Johnson's algorithm performs better than Floyd–Warshall, so it is the better choice there.
  • More detail than this does not seem necessary.

Minimum spanning tree

  • A spanning tree is a subgraph that connects all vertices of the graph and contains no cycle.
    • When edges are weighted, the MST connects all the vertices at minimum total cost.
    • The solution is not unique.
    • Defined on undirected weighted graphs; weights must be positive.
    • The solution is always a tree, so it has no cycle. A tree with n nodes always has n − 1 edges.
  • Generic MST algorithm
    1. Start with A = ∅.
    2. Find an edge that is safe for A and add it to A.
    3. Repeat step 2 until there are n − 1 edges.
  • Kruskal's algorithm (greedy)
    1. Sort the edges by weight in ascending order.
    2. Take the edges one by one in that order, skipping any edge that would form a cycle with the edges already chosen.
    3. Stop when n − 1 edges have been chosen.
    Time complexity: O(E log E) = O(E log V).
  • Prim's algorithm (greedy)
    1. Pick an arbitrary start node.
    2. Grow the tree from the start node.
    3. At each step, choose the lightest edge that connects a node already in the tree to a node not yet in the tree.
    Time complexity: O(E log E) = O(E log V) with a priority heap; O(V²) without one.
  • Prim and Kruskal produce the same total edge weight, but the chosen edges may differ.

Pre-order, in-order, and post-order traversal

  • Pre-order: print a node the first time it is visited.
  • In-order: print a node the second time it is visited.
  • Post-order: print a node the third time it is visited.

Dynamic programming

  • Write a recurrence.
  • Solve the recurrence either with memoization (top-down: cache intermediate results to avoid repeated computation, and solve only the subproblems actually needed) or bottom-up (no recursion overhead).

Optimal substructure

  • A problem has optimal substructure if an optimal solution can be constructed efficiently from optimal solutions of its subproblems.
  • Divide and conquer, greedy algorithms, and dynamic programming all exploit optimal substructure.

Recursion

  • How does a recursion avoid an infinite loop? Think of the Fibonacci numbers.
    • Base case: there must be at least one case that does not recurse.
    • Recursive case: repeated recursion must eventually converge to the base case.
  • A recursive function P should have an execution path on which it does not call itself.
  • P should either refer to a global variable or have at least one parameter.

2-SAT vs. 3-SAT

  • 2-SAT is in P.
  • 3-SAT is in NP (NP-complete).

P and NP

  • P stands for polynomial time: problems that can be solved by a deterministic machine in polynomial time.
  • NP stands for non-deterministic polynomial time: problems that can be solved by a non-deterministic machine in polynomial time.
  • NP-hard problems are at least as hard as the hardest problems in NP.
    • Not all NP-hard problems are in NP.
    • A problem X is NP-hard if, for every problem Y in NP, there is a polynomial-time reduction from Y to X.
  • A problem is NP-complete if it is both in NP and NP-hard.
    • To prove that problem A is NP-hard, reduce a known NP-hard problem to A.
    • If Q is NP-complete and Q is polynomial-time reducible to R, then R is NP-hard (and so R is not in P unless P = NP).
    • If every problem in NP can be reduced to X, then X is NP-hard.

Depth and height in a tree

  • Depth is counted from the root, starting at 0.
  • Height is counted from the leaves, starting at 0.

Maximum flow

  • Max-flow algorithms are not greedy.
  • Ford–Fulkerson
    • Uses DFS.
    • Time complexity: O(E · f), where f is the maximum flow of the network.
  • Edmonds–Karp (a modified form of Ford–Fulkerson)
    • Uses BFS.
    • Time complexity: O(V · E²).

AVL tree

  • A binary search tree in which, for every node, the heights of the left and right subtrees differ by at most 1.
  • Rotations may be required on insertion or deletion.
  • The height of the tree cannot exceed 1.44 · log N, where N is the number of nodes.
  • Search, insert, and delete take O(log N).

Red–black tree

  • Each node is colored red or black.
  • The root and the leaves (NIL) are always black.
  • If a node is red, its children are black.
  • All paths from a node to its NIL descendants contain the same number of black nodes (the black height).
  • Each node needs one storage bit to keep track of its color.
  • The longest path P (root to farthest NIL) is no more than twice the length of the shortest path p (root to nearest NIL): P ≤ 2p.
  • Number of NIL leaves = 1 + number of interior nodes.
  • Rotations may be required on insertion and deletion.
  • Search, insert, and delete take O(log N).

B-tree

  • Rotations are not required.
  • All leaves have the same depth.
  • Height = number of disk operations.
  • Height ≤ logt((N + 1) / 2), where t is the minimum degree of the B-tree.
  • Search, insert, and delete take O(log N).

Simple graph

  • Also called a strict graph.
  • Unweighted, undirected, no loops, and no multiple edges between nodes.

Loop invariant

  • A property that does not change before and after each iteration of a loop.
  • It is true at the beginning of each execution of the loop and at the completion of the loop.

Singly vs. doubly linked list

  • The following applies to both (singly: think of a pointer to the first node; doubly: pointers to the first and last nodes).
  • Singly linked list: search O(N), insertion O(1), deletion O(1).
  • Doubly linked list: search O(N), insertion O(1), deletion O(1).
  • Insertion
    1. Create the new node.
    2. Point the previous node at the new node.
    3. Point the new node at the next node.
  • Deletion
    1. Suppose we want to delete B from A → B → C.
    2. Make A → C (A's pointer now points to C instead of B) while leaving B → C as it is.
    3. Remove B.

Common data structures and their time complexities

Clique

  • A subgraph that is also a complete graph.
  • Clique decision problem: decide whether a clique of size k exists in the given graph.
  • The clique decision problem is NP-complete.

Eulerian vs. Hamiltonian

  • An Eulerian circuit/path uses every edge in the graph exactly once.
    • An Euler path exists when exactly two vertices have odd degree.
    • An Euler circuit exists when no vertex has odd degree.
  • A Hamiltonian circuit/path visits every vertex exactly once.

Circuit vs. path

  • Circuit: starts and ends at the same vertex.
  • Path: does not need to start and end at the same vertex.

Boolean logic

  • AND: A · B
  • OR: A + B
  • NOT: ¬A
  • NAND: ¬(A · B) = ¬A + ¬B
  • NOR: ¬(A + B) = ¬A · ¬B
  • XOR: A ⊕ B = (A + B) · (¬A + ¬B) = A · ¬B + ¬A · B
  • XNOR: A ⊙ B = (A + ¬B) · (¬A + B) = A · B + ¬A · ¬B
