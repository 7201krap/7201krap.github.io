Sample questions

Questions in the style of the exam, with short answers.

  1. Which of the following in-place sorting algorithms needs the minimum number of swaps?
    1. Insertion sort
    2. Quick sort
    3. Heap sort
    4. Selection sort

    Answer: (4) Selection sort. Selection sort is an in-place algorithm with the minimum number of swaps.

  2. A cache has an access time of 30 ns and main memory has an access time of 150 ns. What is the average access time of the CPU, assuming a hit ratio of 80%?

    Answer: 60 ns. (30 × 0.8) + ((30 + 150) × 0.2) = 60.

  3. What is the minimum number of two-input NAND gates needed to implement a two-input OR gate?

    Answer: 3 NAND gates.

  4. At low multiprogramming levels, throughput increases as the multiprogramming level increases. This is best explained by the fact that, as the multiprogramming level increases,

    Answer: the potential for concurrent activity among system resources increases.

  5. At intermediate multiprogramming levels, the rate of increase of throughput with the multiprogramming level decreases. This is best explained by the fact that, as the multiprogramming level increases,

    Answer: some system resource begins to saturate (becomes 100% utilized).

  6. Let A and B be two sets of words (strings) over Σ*, for some alphabet Σ. Suppose B is a subset of A. Which of the following must always be true?
    1. If A is finite, then B is finite.
    2. If A is regular, then B is regular.
    3. If A is context-free, then B is context-free.

    Answer: I is true; II and III are false.

  7. Two processors, M-5 and M-7, implement the same instruction set. M-5 uses a 5-stage pipeline and a clock cycle of 10 ns. M-7 uses a 7-stage pipeline and a clock cycle of 7.5 ns. Which of the following is (are) true?
    1. M-7's pipeline has better maximum throughput than M-5's pipeline.
    2. The latency of a single instruction is shorter on M-7's pipeline than on M-5's.
    3. Programs executing on M-7 will always run faster than programs executing on M-5.

    Answer: I is true; II and III are false.
    I: throughput depends only on the clock cycle. II: latency is (number of stages) × (longest stage time), so M-5's latency is 5 × (longest stage) and M-7's is 7 × (longest stage). III: obviously false.

  8. An aid to determining whether deadlock has occurred is:

    Answer: a resource allocation graph.

  9. Which of the following is (are) true about virtual memory systems that use pages?
    1. The virtual address space can be larger than the amount of physical memory.
    2. Programs must be resident in main memory throughout their execution.
    3. Pages correspond to semantic characteristics of the program.

    Answer: I is true; II and III are false.

  10. Which of the following is an efficient method of cache updating?
    1. Snoopy writes
    2. Write through
    3. Write within
    4. Buffered write

    Answer: (1). The ability of cache controllers to observe activity on the bus and take appropriate action is called the snoopy-cache technique. For performance reasons it is important that snooping does not interfere with the normal operation of a processor and its cache.

  11. Increasing the number of buffers is likely to do which of the following?
    1. Increase the rate at which requests are satisfied (throughput).
    2. Change the likelihood of deadlock.
    3. Change the ease of achieving a correct implementation.

    Answer: I is true; II and III are false.

  12. How many page faults can a single load word (lw) instruction cause, if page tables are not locked in memory and may be swapped to disk?

    Answer: at most 2 per phase. In the worst case the page table itself is not in memory, so bringing it in causes one page fault. The page containing the word may then also be absent, causing a second page fault. This can happen in both the fetch and the execute phase.

  13. If L1 is a decidable language and L2 is an undecidable language, then L1 ∪ L2 is

    Answer: infinite, but possibly decidable and possibly undecidable. A decidable language can be finite or infinite; an undecidable language is always infinite.

  14. Let G = (V, E) be a connected, undirected graph, and let a and b be two distinct vertices in V. Let P1 be the problem of finding a shortest path between a and b, and P2 the problem of finding a longest simple path between a and b.

    Answer: P1 can be solved in polynomial time, but P2 is not known to be solvable in polynomial time (it is NP-complete). The exception is a DAG: the longest path in a DAG can be found in linear time.

  15. One garbage collection algorithm is semispace copying collection. Which of the following characteristics apply to it?
    1. Collects dead objects that reference each other.
    2. Incurs overhead on every assignment to a reference variable.
    3. Avoids fragmentation.

    Answer: I and III are true; II is false.

  16. Of the following problems on a given undirected graph G, which is currently known to be solvable in polynomial time?
    1. Finding the longest simple cycle in G
    2. Finding the shortest cycle in G
    3. Finding all spanning trees of G
    4. Finding the largest clique in G
    5. Finding a node coloring of G (adjacent nodes receive distinct colors) with the minimum number of colors

    Answer: (2).

  17. True or false?
    • Finding the shortest cycle in an undirected graph G is solvable in polynomial time. True.
    • The purpose of a compiler is to translate source code into machine code. True.
    • Every finite language is decidable. True.
    • The halting problem is undecidable. True.
