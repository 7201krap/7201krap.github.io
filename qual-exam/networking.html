Networking

OSI model

  • Layer 7, Application
  • Layer 6, Presentation. Converts the system-dependent representation of data into an independent form. Data compression and encryption.
  • Layer 5, Session
  • Layer 4, Transport. Unit: segment (TCP) or datagram (UDP). Controls the reliability of a link through flow control, segmentation and desegmentation, and error control. It keeps track of segments and retransmits those that fail.
  • Layer 3, Network. Unit: packet. Responsible for packet forwarding, including routing through intermediate routers.
  • Layer 2, Data link. Unit: frame.
  • Layer 1, Physical. Unit: bit.

Client–server vs. peer-to-peer

  • Client–server requires central servers that respond to client requests.
  • Peer-to-peer decentralizes resources; data can be located anywhere, on any connected device.

CSMA/CD

  • Carrier Sense Multiple Access with Collision Detection.
  • A network protocol for carrier transmission that operates in the Medium Access Control (MAC) layer.
  • It senses (listens to) whether the shared channel is busy and defers transmission until the channel is free.

TCP timers

TCP uses four timers to keep the connection reliable.

  • Retransmission timer: started every time a segment is sent. If no ACK arrives within the retransmission timeout (RTO), the segment is retransmitted.
  • Persistent timer: used to avoid a deadlock.
  • Keep-alive timer: prevents an established connection from sitting idle for a long time.
  • Time-wait timer: after a TCP connection is closed, data still in flight may arrive. This timer is used to discard duplicated (retransmitted) or delayed packets.

Ethernet

  • Uses packet switching.
  • Packets sent on Ethernet are limited in size.
  • Uses the CSMA/CD protocol to transmit messages.
  • Uses buses with multiple masters.

Address Resolution Protocol (ARP)

  • Determines the hardware (MAC) address for a given IP address.
  • Translates the logical address assigned in software (IP address) into the actual physical address (MAC address).

Parity bit

  • A bit added to detect whether an error occurred during transmission.
  • Even parity: the parity bit is chosen so that the total number of 1s is even.
  • Examples (parity bit added at the front):
    • 0000000 → 0 0000000
    • 1010001 → 1 1010001
    • 1101001 → 0 1101001
    • 1111111 → 1 1111111

Datagram (UDP)

  • A datagram may be fragmented during routing.
  • Datagrams are reassembled only at the destination.

Round-trip time (RTT)

  • The time it takes for a packet to make a round trip. The ping command reports the round-trip time of IP packets.

TCP handshake

  • Before an application using TCP/IP sends data, it establishes a session with the other computer to guarantee correct delivery.
  • The correct order of the three-way handshake is SYN, SYN/ACK, ACK.
