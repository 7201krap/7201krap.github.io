Operating systems

Static vs. dynamic type checking

  • Static type checking: the type of a variable is known at compile time rather than at run time.
  • Dynamic type checking: type safety is verified at run time. Type checking at run time adds overhead.

Process state transitions

  • The OS uses preemptive scheduling.
  • Dispatch latency
    • The time to stop one process and start running another.
    • The amount of time it takes for a system to respond to a request for a process to begin operation.
    • The dispatcher moves a process from the ready state to the running state.

Virtual memory

  • Logical memory (generated by the CPU) → page table → physical memory (RAM) or HDD/SSD (virtual memory).
  • Can be larger than the amount of physical memory (RAM).
  • Supplementing RAM with secondary storage (HDD/SSD) in this way is called virtual memory.
  • Each application (process) has its own view of memory, known as logical memory.
  • Pages in secondary memory are brought back into main memory when the process needs them again.
  • With segmented memory, a large process may not get access to memory very often.
  • Paged memory makes better use of free space.

Page fault

  • If the demanded page is not present in main memory, we call it a page fault.
  • It occurs when the CPU generates a logical address for a page that is not in physical memory.
  • Steps to handle a page fault (the numbering below is unrelated to the numbers in the figure):
    1. The OS looks at the process control block (PCB) to decide:
      • if the reference is invalid, abort;
      • if the page is simply not in primary memory, load it from secondary memory.
    2. Get an empty frame.
    3. Swap the page into the frame via a disk operation.
    4. Reset the page table to indicate that the page is now in memory.
    5. Restart the instruction that caused the page fault.

Internal fragmentation (paging) vs. external fragmentation (segmentation)

  • Internal fragmentation occurs when memory is distributed in fixed-size blocks. It is the difference between the memory allocated and the memory actually required by a process: the process is given more space than it needs, and the excess is wasted.
  • External fragmentation exists when there is enough total memory to satisfy a request but the available space is not contiguous: storage is fragmented into a large number of small holes.
  • External fragmentation is handled by compaction, which moves allocated blocks so that the free space becomes one contiguous region.

User mode (bit = 1) vs. kernel mode (bit = 0)

  • User mode: only limited access to system data is allowed and the hardware cannot be accessed directly. Application programs run in user mode.
  • Kernel mode: CPU instructions that require special privilege run in kernel mode.

Software pipelining

  • Software pipelining is a form of out-of-order execution, except that the reordering is done by the compiler instead of the processor.
